How the work piles up

Same idea, zoomed out: as the toy box grows from a handful to a hundred, here's how many moves each strategy takes. The dot marks your current slider position.

O(1) — labeled cubby O(log n) — guessing game O(n) — one by one O(n²) — every pair
The point of Big O: it doesn't count exact seconds — it describes how the number of moves changes as the pile gets bigger. O(1) never grows. O(log n) grows whisper-slowly. O(n) grows steadily, one move per extra toy. O(n²) grows explosively — double the toys, and the work roughly quadruples.
